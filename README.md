# Theo! (prototype)

A phone-first card game prototype (Yaniv-style rules, renamed Theo!/Mateo!): win rounds for coins, buy power cards, beat each city's champion, and duel rivals.

Play: https://yuvalbuk07-boop.github.io/theo/

On iPhone, open the link in Safari, tap Share, then "Add to Home Screen" to install it as an app that works offline.

Progress (coins, tickets, cards) is saved on each device only. Opponents are bots.
